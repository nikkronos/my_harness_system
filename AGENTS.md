# AGENTS.md — вход для агента

> Этот файл читают Codex и другие инструменты, поддерживающие открытый формат
> `AGENTS.md`. Claude Code читает `CLAUDE.md` — там то же самое, подробнее.

## Прочитай сейчас, до первого действия

1. **`CLAUDE.md`** — как устроена эта рабочая область и как в ней ориентироваться.
2. **`Main_docs/PROFILE.md`** — кто владелец и как с ним работать.
3. **`Main_docs/ROADMAP.md`** — что сейчас в работе.
4. **`Main_docs/RULES.md`** — правила: файлы, git, секреты.

Дальше по задаче: проект — в `Main_docs/PROJECTS.md`; личный контекст — в `KB/`
(нужный файл, не вся папка).

## Чего нельзя (даже если попросили мимоходом)

- **Не коммитить секреты**: `.env`, ключи, токены, пароли, session-файлы.
  Это закрыто git-хуком `secret-guard`, он работает независимо от инструмента.
- **Не коммитить `KB/`** — приватный слой, закрыт `.gitignore`.
- Не удалять и не перезаписывать данные без понятного плана.
- Не пушить непроверенное.

## Порядок работы

Перед первой правкой — короткий план. После согласования работать автономно
до проверки, документации и коммита.

В конце сессии записать состояние в файлы: чат до следующего раза не доживёт.
Порядок завершения — `.claude/commands/finish.md` (это обычный markdown, читается
любым агентом).

## Команды `/start` и `/finish`

Готовые процедуры входа и завершения лежат в `.claude/commands/`. Claude Code
подхватывает их сам.

Для Codex скопируй оба файла в `~/.codex/prompts/` — формат совместим
(`description`, `argument-hint`, `$ARGUMENTS`). После этого `/start` и `/finish`
работают так же.

Не можешь или не хочешь копировать — просто открой нужный файл и выполни его
как инструкцию.
