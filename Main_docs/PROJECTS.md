# Карта проектов

> Source of truth по статусам, путям и Git-границам твоих проектов.
> Агент сверяется с этим файлом, прежде чем трогать проект.
>
> 🛠️ ШАБЛОН. Заполняй по мере появления проектов.

## Статусы

- **В работе** — активно развивается сейчас.
- **Рабочий** — полезный, но не текущий фокус.
- **Архив** — завершён, не запускать без явной задачи.

## Git-границы

Если внутри рабочей области несколько репозиториев — перечисли их здесь, чтобы
агент не перепутал, куда коммитить:

| Каталог | Репозиторий |
|---|---|
| корень | <— основной repo или «локально» —> |
| <— Projects/X —> | <— отдельный repo —> |

Перед коммитом всегда `git rev-parse --show-toplevel` из каталога проекта.

## Правило для агента

1. Сначала определить проект и прочитать его локальные файлы (`README`, `CLAUDE.md`,
   если есть).
2. Проверить Git-root до изменений и перед коммитом.
3. Не запускать архивные проекты без явной задачи.
4. При изменении статуса/пути проекта — обновить этот файл.
