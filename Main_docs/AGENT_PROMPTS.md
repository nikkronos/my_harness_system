# Готовые prompts для агента

Основные правила уже лежат в `CLAUDE.md`, `Main_docs/PROFILE.md`,
`Main_docs/RULES.md`, `Main_docs/PROJECTS.md` — повторять их в чате не нужно.

Здесь — короткие prompts, которые пригождаются постоянно. Копируй нужный целиком.

## Ознакомление без изменений

Когда заходишь в незнакомый (или подзабытый) проект и не хочешь, чтобы агент
сразу начал что-то менять.

```text
Прочитай стартовый контекст и локальную документацию проекта.
Пока ничего не меняй.

Сообщи:
- что понял;
- факты / гипотезы / риски / open loops;
- минимальный план;
- какие вопросы действительно блокируют работу.
```

## Реализация

```text
Работай автономно по согласованному плану.
Сохраняй существующие изменения пользователя.
Не усложняй архитектуру без практической причины.
После реализации проверь diff, связанные функции и релевантные тесты.
```

## Ревью

```text
Проведи code review. Сначала перечисли проблемы по приоритету:
ошибки, регрессии, безопасность, риск данных/денег/прода и недостающие тесты.
Каждую проблему привяжи к файлу и строке.
Если проблем нет, скажи это прямо и укажи остаточный риск.
```

## Завершение

```text
Проведи финальную проверку задачи.
Обнови документацию проекта, если она есть (не создавай формально ту, которой нет).
Проверь Git-root, remote, diff, тесты и отсутствие секретов.
Закоммить и отправь только проверенное состояние в правильный remote.
Если commit или push не выполнены, явно объясни причину.
Дай компактный итог и open loops.
```
